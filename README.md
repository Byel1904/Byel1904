## 👨‍💻 Sobre mim

Sou estudante de **Técnico em Desenvolvimento de Sistemas pelo SENAC**, com interesse em tecnologia, desenvolvimento de software e resolução de problemas reais.

**Proteção Digital com Inteligência Artificial**
